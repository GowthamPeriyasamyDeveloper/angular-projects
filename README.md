# Angular Projects

A collection of Angular projects demonstrating various Angular concepts and features.

## 📋 Overview

This repository contains multiple Angular projects and demonstrations, showcasing best practices and common patterns in Angular development.

## 📁 Projects

### 1. **Angular 20 Routing Demo**
- **Path:** `angular20-routing-demo/`
- **Description:** A demonstration project showcasing Angular's routing capabilities and navigation patterns. 
- **Key Features:**
  - Route configuration and setup
  - Navigation between components
  - Route parameters and query strings
  - Lazy loading modules

### 2. **RxJS Demo**
- **Path:** `rxjs-demo/`
- **Description:** A project demonstrating RxJS (Reactive Extensions for JavaScript) concepts and patterns commonly used in Angular applications.
- **Key Features:**
  - Observable creation and subscription
  - Operators (map, filter, merge, etc.)
  - Subject and BehaviorSubject
  - Async operations

## 🛠️ Tech Stack

- **Language:** TypeScript
- **Framework:** Angular
- **Reactive Programming:** RxJS

## 📦 Prerequisites

Before you begin, ensure you have the following installed:
- **Node.js** (v16 or higher)
- **npm** (v7 or higher) or **yarn**
- **Angular CLI** (latest version)
